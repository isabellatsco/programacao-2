# programacao-2
 Atividades da disciplina de Programação 2

| Atividade | Como rodar | URL |
|---|---|---|
| ap1) servidor HTTP com Node | `cd ap1 && npm start` | http://localhost:1000 |
| ap3) API de produtos e fornecedores com Express | `cd ap3 && npm install && npm run dev` | http://localhost:3000/api |
| ap3.1) front-end EJS consumindo a API da ap3 | `cd ap3.1 && npm install && npm run dev` | http://localhost:3100 |
| ap4) app console consumindo a API da ap3 | `cd ap4 && npm install && npm start` | — (consome http://localhost:3000/api) |
| ap5) API demo_flight com PostgreSQL, Prisma e JWT | `cd ap5 && cp .env.example .env && npm install && npm run db:up && npm run dev` | http://localhost:5000/api |
